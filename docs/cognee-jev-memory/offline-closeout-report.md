5. Retained optional backend job handles in bounded private accepted-job records. HTTP acceptance, local receipt persistence and searchability are separate. The client waits at most 250 ms / 4 KiB for an optional acknowledgment; timeout after acceptance cannot authorize another write.
6. Fixed helper same-key TTL expiration and provider budget partitioning. Cached decisions/skips are not network requests; actual helper invocation and unknown wire counts stay separate. Late observations preserve the originating session and dataset.
7. Added shared-deadline and cancellation tests for legacy alias lookup; symlink/nested/moved repository identity tests; coalescing for repeated task signals; bounded local resident refresh for facts committed by another writer.
8. Corrected evaluation accounting: the unexecuted JEV arm has no fabricated C-arm metrics, and prepared evidence is not treated as delivered-to-model or used. Added real metadata fixtures and a temp-profile mode/rollback dry-run.
9. Fixed default-feature `strict_schema` warnings and the harness test race caused by opposite process-global turn-budget settings. A separate auth-cancellation test now uses bounded lock reacquisition rather than assuming instant cross-process availability; cancellation and credential-integrity assertions remain.
