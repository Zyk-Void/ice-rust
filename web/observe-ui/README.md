# observe-ui

The `icers --observe` dashboard: Angular, [spartan/ui](https://spartan.ng)
components (Helm code in `libs/ui/`, generated by `@spartan-ng/cli`) and
TanStack Charts through spartan's chart component.

icers embeds the built bundle from `crates/ice-cli/src/observe/ui/`; building
icers needs no Node. After changing anything here, run from the repository
root and commit the result:

```bash
sh scripts/build-observe-ui.sh
```

The build must stay a single `main.js` plus `styles.css` (eager routes, no
external assets): the server embeds exactly those files and its CSP allows only
its own origin.

## Development

```bash
npm ci
npm test -- --watch=false     # unit tests (Vitest)
ICERS_OBSERVE_TOKEN=<token> npm start
```

`npm start` serves on `http://localhost:4200` and proxies the API to a running
`icers --observe` (`ICERS_OBSERVE_URL`, default `http://127.0.0.1:4659`). The
token is in the dashboard URL icers prints, and in
`~/.icers/agent/observe.token`.

Add spartan components with `npx ng g @spartan-ng/cli:ui --name=<component>`.
See `docs/guides/observability.md` for what each view shows.
